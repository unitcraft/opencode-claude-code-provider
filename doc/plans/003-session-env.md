# План 003 — сессия OpenCode в окружении Claude Code

**Статус:** ЗАКРЫТ 2026-10-05.
**Где остановились:** сделано; включается перезапуском сервиса OpenCode.
**Проверено:** тест `lib` (`claudeEnv`), живая проверка в песочнице.

## Цель

Хуки репозитория, которые Claude Code исполняет во вкладке claude-code, знают, за какую вкладку OpenCode они
работают. Нужно хуку `Stop` проекта nova (код «жду <чего>» проверяется по файлу состояния этой сессии у
opencode-peers, план peers 004) и любому хуку, которому важна вкладка.

## Решения

| № | Решение | Кто | Дата |
|---|---------|-----|------|
| 1 | Переменная `OPENCODE_SESSION_ID` (id сессии OpenCode) в окружении процесса Claude Code каждого хода окна; её видят хуки и команды, которые запускает Claude Code | Claude, по «да» владельца на проверку «жду» | 2026-10-05 |

## Сделано

`claudeEnv(base, {account, threshold, session})` в `src/lib.js` собирает окружение хода: `CLAUDE_CONFIG_DIR`,
`CLAUDE_CODE_AUTO_COMPACT_WINDOW`, `OPENCODE_SESSION_ID`. Ход окна, `/compact` и пробный ход (инструменты, навыки)
передают id сессии.
